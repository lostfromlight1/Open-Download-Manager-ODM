Version 1.0.0

Open Download Manager

An open-source download manager for Windows, macOS, and Linux. The installer sets up the app and the browser host. You load the browser extension yourself.

  • Windows installer 64-bit, every account on the PC
  • Linux rpm Fedora and other rpm systems, 64-bit
  • Linux deb Debian and Ubuntu, 64-bit
  • macOS disk image macOS 12 or newer, Apple Silicon

All release files and checksums

After you install

  1. Windows may show SmartScreen. Choose More info, then Run anyway, only for the installer from this site. macOS may block the first open. Right-click the app and choose Open.
  2. ODM uses your Downloads folder and turns browser integration on.
  3. Chrome or Edge: open chrome://extensions, turn on Developer mode, and load the browser-extension folder from the install. Linux uses /usr/share/odm/browser-extension. On macOS it is inside odm.app under Contents/MacOS.
  4. Firefox: load browser-extension-firefox/manifest.json as a temporary add-on. Load it again after Firefox quits.

The same steps are in the app under Help, and in Getting started.

Not in this release

  • Intel Macs, and an AppImage.
  • Flatpak browsers. They cannot start /usr/bin/odm-nmhost.
  • A managed ffmpeg build on macOS. YouTube there needs brew install ffmpeg.
